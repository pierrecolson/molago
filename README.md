# Molago 2.0

Refonte complète de Molago : un outil personnel pour apprendre le vocabulaire coréen de la vie quotidienne, à travers du contenu généré qui donne envie de revenir chaque jour.

- `archive/v1/` — l'ancienne application (flashcards / ajout de mots), conservée pour référence.
- `docs/research/` — base de connaissances sur l'apprentissage des langues, le coréen, et la motivation (générée par recherche approfondie).

Le design de la v2 est en cours de définition.
