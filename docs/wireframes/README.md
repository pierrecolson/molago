# Maquettes

Maquettes fil de fer produites pendant l'entretien de conception du 25 juillet 2026.
Ouvrir les fichiers `.html` directement dans un navigateur.

**Ce sont des schémas de structure, pas une direction visuelle.** Les couleurs, la
typographie et l'identité seront traitées dans une session dédiée. Ce qui compte ici,
c'est la disposition, la hiérarchie et le comportement.

| Fichier | Ce qu'il montre | Retenu |
|---|---|---|
| `morning-screen.html` | Trois dispositions pour l'écran du matin | **A** — trois cartes égales |
| `meta-line.html` | Premières formulations de la ligne d'information | Aucune — chiffres ambigus |
| `meta-line-v2.html` | Durée + nombre / sensation / durée seule | **B** — la sensation |
| `reader.html` | Flux continu, blocs, et le panneau de mot | Les deux, en réglage |
| `word-panel.html` | Traitements de la famille de racine | Écarté — famille trop tassée |
| `word-panel-v2.html` | Le panneau à trois étages | **Retenu** |
| `swipe.html` | Les deux directions de swipe | **Retenu** |
| `quiz.html` | Choix multiple, clavier, et l'état après réponse | **Les deux**, selon la maturité du mot |
| `notebook.html` | Journal, tri par état, mur de mots | **A** — le journal |
| `confidence.html` | Jauge de confiance inspirée de Strava | **A** — la jauge |
